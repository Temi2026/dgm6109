Unexpected Engagements vs Time Management Effectiveness

Hypothesis: As the number of unexpected engagements increases, perceived time management effectiveness decreases.

This visualization explores how unexpected engagements influence time management effectiveness. The X-axis shows the number of unexpected engagements while the Y-axis shows perceived time management effectiveness. The color of each circle represents the number of scheduled commitments, helping to show whether productivity changes when commitments increase.

Legend: Darker color = more scheduled commitments
