Effect of Scheduled Commitments on Planned Activity Time

Hypothesis: As the number of scheduled daily commitments increases, the total time spent on planned activities increases.

This scatterplot explores whether having more scheduled commitments leads to spending more time on planned activities. The X-axis represents the number of commitments while the Y-axis shows the hours spent on planned activities. The size of each circle represents the number of unexpected engagements, allowing us to see whether interruptions affect productivity.

Legend: Larger circles = more unexpected engagements
